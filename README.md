
# Monorepo

A monorepo containing web, API, UI, and database packages.

## Packages

- `apps/web` - Next.js web application
- `apps/api` - API server
- `packages/ui` - Shared UI components
- `packages/db` - Database schema and client

## Getting Started

Install dependencies:

```bash
npm install
```

Build all packages:

```bash
npm run build
```
