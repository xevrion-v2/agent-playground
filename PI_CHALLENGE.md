# Pi Precision Challenge

A lightweight mathematical benchmark suite calculating $\\pi$ using infinite series algorithms.

## Implemented Algorithms

1. **Leibniz Formula**
   \\frac{\\pi}{4} = 1 - \\frac{1}{3} + \\frac{1}{5} - \\frac{1}{7} + \\dots
   - Classical alternating series.

2. **Nilakantha Series**
   \\pi = 3 + \\frac{4}{2 \\times 3 \\times 4} - \\frac{4}{4 \\times 5 \\times 6} + \\frac{4}{6 \\times 7 \\times 8} - \\dots
   - Rapid convergence yielding high accuracy.
